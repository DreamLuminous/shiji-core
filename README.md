# 时己 Shiji：个人经验主权系统

> GitHub 核心公开版 · v0.1.0

时己是一套以个人经验主权为核心的本地优先系统方案，关注记录、检索、数据迁移、用户确认和有来源的 AI 辅助解释。

本仓库只公开可供讨论和复现的核心技术文档。商业规划、个人发展路线、团队与资源计划、供应链信息、用户规模假设、研究材料和敏感应用方案未纳入公开版本。

## 开放范围与授权说明

本仓库当前用于公开“时己 Shiji”的部分技术理念、系统设计与通用规范，不包含完整产品源码、商业规划、内部实现、运营资料及敏感数据。

除另有明确说明外，本仓库内容保留全部权利。仓库公开不代表授权商业使用、复制发布或用于衍生商业产品。

后续将根据项目发展情况，逐步开放社区基础能力，并为社区版本与商业版本分别制定许可证。

## 阅读顺序

建议先阅读项目概述、核心理念和产品定位，再进入软件功能、数据模型、工程实现、安全与测试规范。

## 公开原则

- 示例身份、设备、事件和记录标识均为虚构值。
- 不包含真实用户资料、联系方式、内部路径、访问凭据或未公开项目名称。
- 规划、预算、市场、商业模式和个人长期安排不在本仓库讨论。
- 文中路线和技术方案仍属于设计材料，实际实现状态以代码、测试和发布记录为准。
