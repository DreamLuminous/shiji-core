# 7 个人经验数据库与回忆系统

[返回总目录](../README.md)

返回目录  ·  阅读导航

计划在第 3 至 6 个月推进经验组织。前置条件是记录、保存、检索和迁移闭环已通过验收。本阶段增加个人经验数据库（Personal Experience Database），让用户把离散记录关联为主题、项目和成长过程。

## 7.1 为什么需要个人经验数据库

一条经历可能与多年后的活动有关。例如，用户从接触无人机、购买设备到参与航拍项目，再转向相关软件开发。时间排序展示事件先后，主题和项目关联进一步帮助用户回顾长期兴趣。关联不自动表示因果关系。

Experience Graph 表示用户确认的经验关联网络。每条边需能追溯到建立方式和相关记录。

## 7.2 经验对象模型升级

保留 Moment 作为基本记录，新增 Experience 组织长期主题。Project 和 Goal 分别管理持续项目与目标，不替代原始记录。

### 7.2.1 Moment 瞬间记录

表示：某一个时间点发生的事情。例如：“今天想到硬件方向。”，属性：

```json
{
id:"",
time:"",
content:"",
type:"thought"
}
```

### 7.2.2 Experience 经验节点

表示：长期形成的主题。例如：“软件开发能力”。它可能来自：多个Moment。结构：

结构要素：Experience；Moment；Attachment。

### 7.2.3 Project 项目对象

针对：长期项目。例如：示例图像项目。保存：开始时间；目标；版本；里程碑。数据：

```json
{
"name":"示例图像项目",
"start":"2026-08",
"status":"active"
}
```

### 7.2.4 Goal 目标

例如：“完成长期学习项目。”，包括：创建时间；目标描述；当前状态。

## 7.3 数据库升级设计

本阶段增加对象关系和一致性约束。Web 可继续使用 IndexedDB 及关联表，SQLite 端使用关系数据库；对象契约保持一致，不要求 Web 立即迁移到 SQLite。

Moment表：保存事件。

```text
Moment
{
id
content
time
type
}
```

Experience表：

```text
Experience
{
id
name
description
created_time
}
```

MomentExperience关联表：表示：一个记录属于某经验。例如：记录：“第一次写C++项目”，属于C++学习经验。

```text
MomentExperience
{
moment_id
experience_id
}
```

Project表：

```text
Project
{
id
name
description
start_time
status
}
```

ProjectMoment表：记录：项目过程。

## 7.4 人生时间线系统升级

阶段1：简单时间排序。阶段2：增加：“成长路线”。例如：用户查看：软件开发。系统展示：

流程：2024；学习C语言；2025；完成数据结构学习；2026；开发示例图像项目；2027；硬件探索。

初期关联由用户主动建立。后续自动建议须标注来源，经过确认后才进入正式关系网络。

## 7.5 项目成长记录系统

项目时间线面向论文、软件产品和其他持续任务，帮助用户保存目标、过程、里程碑和复盘记录。

创建项目：用户：创建：“时己项目”。填写：名称：时己，目标：建立个人经验系统。

项目操作流程：填写名称和目标、保存项目，再选择已有 Moment 关联或新建过程记录。添加里程碑时填写事件时间和来源记录；取消关联只移除关系，不删除原始记录。项目归档后仍可检索和导出。

添加里程碑：例如：2026.10，完成第一版规划。2027.01，完成软件原型。数据：

```json
{
"type":"milestone",
"title":"完成软件原型",
"time":"2027-01"
}
```

## 7.6 回忆系统升级

阶段1：往年今日。阶段2：智能回忆。

功能：

### 7.6.1 年度回顾

例如：2027年底。系统生成：

```text
这一年：
你记录了：
356个瞬间。
主要主题：
软件开发
学习
项目实践
重要节点：
完成时己原型。
```

年度回顾先基于可复现统计生成记录数、标签分布和项目节点。应说明统计时间范围、过滤条件和记录覆盖程度；未记录的经历不计入总量，也不据此评价用户。

### 7.6.2 时间胶囊

时间胶囊保存用户给未来自己的内容和计划开启时间。提醒需单独授权；应用未运行或权限被关闭时，应在下次打开时展示到期内容，不能保证定时送达。

```json
{
"type":"capsule",
"open_date":"2027-10"
}
```

## 7.7 经验搜索升级

结构搜索组合关键词、标签、主题、项目和时间范围。对于“什么时候开始关注隐私”等问题，先返回相关记录的最早可见时间，再由用户核查，不能等同于现实中兴趣的绝对起点。

## 7.8 本地智能整理基础

阶段 2 的辅助整理只提出可解释的建议。例如多次出现“示例图像项目”“隐私”“本地处理”时，系统询问是否建立主题。用户确认后创建；拒绝后保留原始记录，不强制分类。

## 7.9 个人知识地图

阶段2后期增加。展示：用户自己的经验网络。例如：

```text
创造
                  |
软件开发 —— 示例图像项目
                  |
              隐私理念
                  |
              时己系统
```

经验地图展示已保存的连接，不根据图形位置、节点大小或连线数量给用户作人格或能力评价。

技术实现：前端：D3.js，或者：ECharts Graph。数据：Graph结构。未来：Neo4j。当前：SQLite关系模拟。
